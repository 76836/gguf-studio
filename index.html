Make model smaller

Two tools: Quantize (fewer bits per weight) and Prune (zero out tiny weights). Both need Export afterward.

Step 1 — Pick weights

Usually you want the big matrix weights, not the tiny norm vectors.

Step 2 — Quantize (recommended)

Compress selected tensors. Q4_0 is the sweet spot for phone/llamafile. Q8_0 is higher quality / larger.

Step 3 — Optional prune

Sets the smallest weights to zero. Does not shrink file size much until you quantize; mostly for experiments.

Drop whole layers

Transformer models are stacked blocks (blk.0, blk.1, …). Removing blocks makes the model much smaller and faster — but dumber unless you train again.

Keep the first N blocks

Example: a 30-layer model → keep 4 → only blk.0…blk.3 remain (renumbered). Then Export.

Tip: for a phone “doorman” style model, try 2–6 layers, then Fine-tune so it still says useful lines.
